# Invigilator Dashboard - Quick Start Guide

## Starting Your Shift

### Before the Exam
1. Log in to the Invigilator Dashboard
2. Verify your network connection (green indicator in top-right)
3. Check that all candidate video feeds are loading
4. Ensure audio monitoring is enabled on your system
5. Clear any previous session alerts

### When the Exam Begins
1. Monitor the candidate list on the left sidebar
2. Watch for any initial connection issues
3. Be prepared to act quickly on critical alerts (red)
4. Keep the alert panel visible and monitored

## Rapid Response Procedures

### When You See a RED Alert (Critical Risk)
1. **Immediately** switch to that candidate's video
2. Observe the video feed directly
3. Review the associated evidence snapshot
4. Decide action:
   - If suspicious: Click "🚩 Flag Session"
   - If false alarm: Click "Acknowledge"
5. Document the incident in your notes

### When You See an ORANGE Alert (High Risk)
1. Switch to the candidate's video
2. Observe for 30 seconds
3. Review evidence
4. Acknowledge if acceptable
5. Flag if behavior is repeated

### When You See a YELLOW Alert (Medium Risk)
1. Review but don't necessarily interrupt exam
2. Monitor candidate more closely for next few minutes
3. Acknowledge routine alerts
4. Escalate if pattern emerges

### When You See a BLUE Alert (Low Priority)
- Monitor for pattern
- Auto-dismisses after 30 seconds
- No immediate action usually required

## Common Scenarios

### Mobile Phone Detected
1. Alert appears with photo evidence
2. Switch to candidate video immediately
3. If confirmed: Flag session
4. If false positive: Acknowledge

### Face Not Visible
1. Usually indicates poor camera angle or lighting
2. May be temporary (candidate looking down)
3. If persistent: Consider pausing to investigate
4. Check with candidate to adjust setup

### Multiple Faces in Frame
1. Indicates possible collaborative cheating
2. Requires immediate action
3. Flag session and document
4. May require pause to investigate

### Tab Switch Detected
1. Indicates candidate accessed different application
2. Confirm violation of exam rules
3. Review confidence score
4. Acknowledge if false positive
5. Flag if confirmed unauthorized tab

### Copy/Paste Activity
1. Shows evidence in alert
2. May indicate attempt to use external content
3. Escalate immediately if detected
4. Flag session for post-exam review

## Dashboard Interpretation

### Risk Score Meter Colors
```
  🟢 GREEN  (0-29):  All Clear - Candidate appears compliant
  🟡 YELLOW (30-59): Monitor - Minor concerns noted
  🟠 ORANGE (60-84): Alert - Significant concerns present
  🔴 RED    (85-100): Critical - Immediate action needed
```

### Risk Trend Line
- Shows 5-minute historical risk progression
- Rising line indicates worsening behavior
- Flat line indicates stable behavior
- Sudden spikes indicate event detected

## Essential Actions

### To Pause a Session
1. Click candidate name in left sidebar
2. Click expand arrow
3. Click "⏸️ Pause Exam"
4. Candidate receives notification
5. Camera and exam timer pause

### To Flag a Session
1. Click candidate name in left sidebar
2. Click expand arrow
3. Click "🚩 Flag Session"
4. Session marked for post-exam review
5. Alert saved with timestamp

### To Acknowledge an Alert
1. Locate alert in right panel
2. Click "Acknowledge" button
3. Alert no longer counts as unreviewed
4. Evidence still available for reference

### To View Evidence
1. Click "Evidence" link on alert
2. Modal opens with full-size image
3. View timestamp and metadata
4. Click download to save
5. Close modal when done

## Keyboard Shortcuts (Use These!)

```
Alt + P     Pause selected session
Alt + F     Flag selected session
ESC         Close any open modal
```

## During the Exam

### Every 5 Minutes
✓ Scan all candidate video feeds  
✓ Check alert panel for new items  
✓ Verify connection status  
✓ Review risk score trends  

### When Alert Volume Increases
✓ Prioritize RED and ORANGE alerts  
✓ Quickly acknowledge BLUE alerts  
✓ Look for patterns indicating systematic cheating  
✓ Escalate if multiple candidates show same behavior  

### If Connection Drops
✓ Watch for red indicator in top-right  
✓ Dashboard auto-reconnects (usually 3-5 seconds)  
✓ If red indicator persists >10 seconds, refresh page  
✓ Contact IT support if unable to reconnect  

## Emergency Procedures

### Complete Exam Failure
1. Note the time
2. Take screenshot of dashboard state
3. Document all affected candidates
4. Contact exam coordinator immediately
5. Follow institution's emergency protocol

### Security Threat (Multiple Violations)
1. Flag all involved candidates
2. Document all evidence
3. Immediately notify exam coordinator
4. Follow institution's security protocols
5. Preserve all evidence for investigation

### Technical Issues
1. Try refreshing page (F5)
2. Check network connection
3. Restart browser if refresh fails
4. Contact IT support with screenshot
5. Have paper backup procedures ready

## End of Shift

1. Review flagged sessions list
2. Document any unresolved alerts
3. Take screenshots of serious violations
4. Export evidence for archiving (if available)
5. Log out securely
6. Close browser window

## Tips for Success

1. **Keep alerts cleared** - Regular acknowledging keeps panel useful
2. **Use thumbnails** - Quickly check multiple candidates
3. **Trust the AI** - High confidence scores (90%+) are usually accurate
4. **Document early** - Flag suspicious behavior immediately
5. **Stay calm** - Some alerts are false positives
6. **Multiple monitors** - If available, put alerts on second screen
7. **Position camera** - Ensure all feeds have proper lighting
8. **Know the rules** - Understand exam policies before shift
