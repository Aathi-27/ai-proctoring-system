# Keyboard Shortcuts Reference

## Primary Actions

| Shortcut | Action | When Available |
|----------|--------|-----------------|
| **Alt + P** | Pause/Resume selected session | Session selected in sidebar |
| **Alt + F** | Flag/Unflag selected session | Session selected in sidebar |
| **Escape** | Close modal or fullscreen view | Modal open |

## Navigation

| Shortcut | Action |
|----------|--------|
| **Tab** | Move focus to next interactive element |
| **Shift + Tab** | Move focus to previous interactive element |
| **Enter** | Activate focused button or link |
| **Space** | Scroll down one page (when focus not on form) |

## Alert Management

| Shortcut | Action | Context |
|----------|--------|---------|
| **A** | Acknowledge focused alert | Alert panel focused |
| **F** | Filter alerts (cycle) | Alert panel focused |
| **C** | Clear all low-priority alerts | Alert panel focused |

## Timeline & Evidence

| Shortcut | Action | Context |
|----------|--------|---------|
| **E** | Expand/collapse focused event | Timeline focused |
| **D** | Download focused evidence | Evidence preview open |
| **R** | Reset timeline to current time | Timeline view active |

## Candidate Selection

| Shortcut | Action | Context |
|----------|--------|---------|
| **1-4** | Switch to candidate video (1-4) | In video grid area |
| **Arrow Up/Down** | Move selection in session list | Session list focused |
| **Enter** | Select focused session | Session list focused |

## System

| Shortcut | Action |
|----------|--------|
| **Ctrl/Cmd + R** | Refresh entire dashboard |
| **Ctrl/Cmd + P** | Print current screen (browser default) |
| **F11** | Enter fullscreen mode (browser default) |
| **?** | Open keyboard shortcuts help modal |

## Notes

- Keyboard shortcuts are case-insensitive
- Alt key may vary by operating system:
  - Windows/Linux: Alt
  - Mac: Option (⌥)
- Shortcuts require focus on appropriate element
- Some shortcuts depend on keyboard layout
- Right-click still available for context menus
- All critical functions available through GUI

## Accessibility Tips

1. **Tab Navigation**: Use Tab and Shift+Tab to navigate the dashboard
2. **Screen Readers**: All elements have proper ARIA labels
3. **High Contrast**: Enable high contrast mode in system settings
4. **Keyboard Only**: All features accessible without mouse
5. **Focus Indicator**: Clear visual focus ring on all elements
